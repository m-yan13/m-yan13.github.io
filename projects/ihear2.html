iHEAR2++

A low-cost portable acoustic measurement system built around synchronized multi-channel acquisition.

FOCUSHardware + embedded
CORESTM32H723VGT6
STATUSTested + measured
PROJECT NOTES

Overview

Designed a portable acoustic measurement system using a five-microphone array and an STM32H723VGT6 control PCB. The system synchronously acquires and transfers five channels of PDM microphone data to a PC.

Testing

Across three recordings, multi-acquisition averaging produced 3.85× noise reduction, corresponding to 11.71 dB.

Signal integrity

Shielded cabling and source-series termination reduced data-clock crosstalk by approximately 80%, bringing interference below the target threshold.

Tools

STM32 · KiCad · PDM · PCB design · Embedded C · Testing

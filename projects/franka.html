ROBOTICS / CONTROL SYSTEMS

DUAL FRANKA ROBOT CONTROL

Coordinated control of two Franka robots using ROS 2 and simulation tools.

OVERVIEW

Developed coordinated robot control using ROS 2, MoveIt 2, KDL-based kinematics, null-space control, and Gazebo simulation.

CONTROL

Worked with collision-free trajectories and robot coordination while accounting for kinematic behavior and system constraints.

INTEGRATION

Integrated a physical robotic gripper and joint-state feedback, and developed a custom grasp-fixation plugin to address rigid-body hand-off instability in Gazebo.

TOOLS

ROS 2 · MOVEIT 2 · KDL · GAZEBO · ROBOTICS

Dual Franka Robot Control

Robotics / Control Systems · A dual-robot control project covering kinematics, trajectory planning, simulation, and physical gripper integration.

PROJECT NOTES

Overview

Built coordinated control for two Franka robots in ROS 2 using MoveIt 2 and KDL-based kinematics.

Control

Implemented null-space control and collision-free trajectories for coordinated robot motion.

Simulation

Used Gazebo to develop and test the system, including a custom grasp-fixation plugin to address hand-off rigid-body instability.

Integration

Integrated a physical robotic gripper and joint-state feedback into the control workflow.

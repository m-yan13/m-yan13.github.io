PCB DESIGN

CUSTOM KEYBOARD PCB

Custom keyboard PCB developed in KiCad from schematic capture through board layout.

OVERVIEW

Designed the keyboard schematic and PCB layout in KiCad, organizing the board around the required electrical connections and physical layout.

DESIGN

Focused on clear schematic organization, PCB routing, component placement, and a layout that could be taken toward fabrication.

STATUS

This project is a PCB design project; the board was designed in KiCad but was not fabricated or assembled.

TOOLS

KICAD · SCHEMATIC CAPTURE · PCB LAYOUT
